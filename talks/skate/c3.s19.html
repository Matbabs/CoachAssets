🧭 Semaine 19 — Les manuals
(L'équilibre sur deux roues)

Le manual c'est skater sur deux roues seulement, comme un vélo. C'est un trick d'équilibre qui demande du contrôle et de la précision. Les manuals sont essentiels dans un run de compétition.

Qu'est-ce qu'un manual ?
Un manual c'est skater en équilibre sur deux roues. Il y a deux types :

  • Nose manual : équilibre sur les roues avant
  • Manual : équilibre sur les roues arrière

Comment apprendre ?

  1. Trouve un espace plat
  2. Pousse pour prendre de la vitesse
  3. Lève doucement le nose ou le tail
  4. Trouve ton équilibre
  5. Maintiens l'équilibre en ajustant ton poids

Les combos

  • Manual + trick + manual
  • Ollie + manual
  • Manual + grind

📓 Cette semaine, tu peux noter :

  • Combien de temps peux-tu tenir un manual ?
  • Quel est le plus facile pour toi ?

L'équilibre, c'est la clé de tout.
