🧭 Semaine 19 - Les manuals

L'équilibre sur deux roues

Rouler en équilibre sur deux roues, comme en vélo : arrière pour le manual, avant pour le nose manual. Essentiel dans un run de compétition.

🛠️ Comment apprendre

  1. Sur du plat, prends un peu de vitesse
  2. Lève doucement le nose ou le tail
  3. Trouve ton point d'équilibre et ajuste ton poids pour le tenir

🔁 Les combos
Ollie + manual, manual + trick + manual, manual + grind.

📓 Cette semaine, note :

  • Combien de temps tu tiens un manual
  • Celui qui est le plus facile pour toi
