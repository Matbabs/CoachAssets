🧭 Semaine 7 — Préparer sa ligne en compétition
(Comment construire un run gagnant)

En skate, une ligne en contest c'est un peu comme une performance en direct : temps limité, espace imposé, et tu dois enchaîner tes tricks sans erreur. Ce qui fait la différence entre un bon run et un run gagnant, ce n'est pas seulement la difficulté des tricks, mais la façon dont ils sont organisés. Une ligne efficace suit une logique : ouverture, construction, pic, fin propre.

1. Comprendre le format d'un run
Dans la plupart des contests modernes (street ou park), tu as :

  • 1 à 3 runs
  • Une durée fixe (souvent 45 secondes à 1 min)
  • Parfois des "best tricks" en plus

2. Lire le park comme une carte
Avant même de penser aux tricks, tu dois identifier :

  • Les obstacles "faciles" (pour sécuriser des points)
  • Les obstacles "à gros score"
  • Les zones de transition
  • Les lignes naturelles (flow du park)

3. Construire une ligne = construire une histoire

  1. Ouverture : trick fiable, mise en confiance, pas de prise de risque
  2. Construction : tricks plus techniques, meilleure utilisation du park
  3. Pic : le trick le plus dur, souvent sur un gros obstacle
  4. Fin propre : sortie maîtrisée, pas de chute inutile

4. Le plus important : la constance
En contest, une règle tacite existe : un run propre bat souvent un run trop ambitieux avec des chutes.

5. Les secrets des pros

  • Visualisation avant le run
  • Avoir 2 ou 3 versions du run (safe, intermédiaire, full send)
  • Lire les autres riders et s'adapter

Ce que les juges regardent vraiment

  • Difficulté, amplitude, style, contrôle, fluidité
  • Est-ce que le run ressemble à quelque chose de maîtrisé ?

📓 Cette semaine, tu peux noter :

  • Comment organiserais-tu ton run idéal ?
  • Quel obstacle est ton "banger" ?

Préparer une ligne, c'est construire une logique de déplacement + une montée en intensité + une exécution propre.
