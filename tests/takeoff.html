Le Take-off (Surf)

🎯 Objectif : Te lever sur des vagues de plus en plus engagées.

📊 Protocole :

  • Test : 3 take-offs réussis sur 5 sur le type de vague visé

🏄 Comment faire : Pop-up en un temps, mains sous la poitrine. Les 2 derniers coups de rame comptent.

📝 Résultat :

  • Niveau 1 : se lever dans la mousse jusqu'au bord
  • Niveau 2 : vague verte, départ en angle sur l'épaule
  • Niveau 3 : take-off tardif dans le creux
